# Distinguished Engineer

Highest individual contributor level. Sets technical direction across the org.

## Responsibilities
- Company-wide technical strategy
- Cross-org architecture alignment
- External representation (conferences, papers, open source)
- Mentorship of principal/staff engineers
- Crisis technical leadership

## Artifacts
- Technical vision documents
- Architecture decision frameworks
- Reference implementations
- External talks/papers
- Mentorship programs

## Principles
1. Impact over activity — measure by outcomes, not output
2. Leverage over effort — multiply through others
3. Long-term over short-term — think in years, not sprints
